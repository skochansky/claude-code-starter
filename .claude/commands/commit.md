## Context
- Status: !`git status --short`
- Staged diff: !`git diff --cached --stat`
- Unstaged diff: !`git diff --stat`
- Recent messages (match their style): !`git log --oneline -10 2>/dev/null || echo '(no commits yet)'`

## Task
1. If nothing is staged, stage the related changes only (never `.env`, never unrelated files). Ask if unsure which files belong together.
2. Write a Conventional Commit message: `type(scope): imperative summary` (max 72 chars), blank line, body explaining *why*.
   Types: feat, fix, refactor, test, docs, chore, perf, ci.
3. No AI co-author or "generated by" lines.
4. Commit. If a hook fails, fix the cause and create a new commit - never `--no-verify`.
